# Module

Терминальная idle-игра: симулятор энергокомпании с атомной станцией.

Игрок управляет компанией — реактор, продажа электроэнергии на рынке, финансы,
поимённый персонал с правами доступа и профсоюзом. Игра бесконечная, идёт
«сама», проигрыш возможен и болезнен. Основной режим: открыл терминал, отдал
приказы, закрыл. Пока процесс закрыт, **не происходит ничего** — время не идёт,
уведомлений нет. Пропущенное досчитывается при следующем запуске.

## Состояние: v0.1.0, фазы 0–2б

Играть уже можно. Блок набирает мощность, энергия продаётся по живой цене,
деньги приходят и уходят, приказы исполняются в игровом времени, компанию можно
разорить.

Готово:

- **сохранения целиком**: атомарная запись, кольцо бэкапов, цепочка миграций;
- игровые часы, детерминированный RNG, планировщик дискретных событий;
- реактор: набор мощности, выработка, выгорание топлива;
- рынок: суточный профиль цены, сезонность, шум с возвратом к среднему,
  суточный расчёт;
- договор PPA: фиксированная цена, срок, штраф за недопоставку — простой под
  договором стоит денег, а не просто не приносит их;
- топливо: контракт с лагом поставки в четыре месяца, своя цена, автозакупка;
- финансы: долг, проценты, ковенанты, банкротство со сроком на исправление,
  переходящий долг между партиями и процедура списания;
- приказы с длительностью: перегрузка топлива, ТО;
- догон пропущенного времени, блокировка партии от вторых копий;
- интерфейс на Textual, тесты и CI.

Ещё нет: персонала и профсоюза, настоящей физики реактора (ксенон, кинетика,
износ), рынка на сутки вперёд, консоли аналитика на Python. Роадмап фаз — в
[docs/PROMPT.md](docs/PROMPT.md), дизайн — в [docs/DESIGN.md](docs/DESIGN.md).

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -e ".[dev]"

.venv/bin/module              # запустить игру
.venv/bin/module doctor       # проверить окружение и сейв
.venv/bin/module save info    # что в текущей партии
```

Установленная игра запускается одним словом: `module` или `mdl`.

Управление:

| Клавиша | Что делает |
|---|---|
| `↑` / `↓` | уставка мощности ±10% |
| `r` | перегрузка топлива (30 суток останова) |
| `m` | плановое ТО (5 суток) |
| `пробел` | пауза |
| `1` / `2` / `3` | скорость 1x / 5x / 50x |
| `s` | сохранить, `d` — тема, `q` — выход |

Блок разгружается и набирает мощность не мгновенно, а за десять часов. Простой
оплачивается из кармана: расходы от мощности не зависят, а если продажа идёт по
договору PPA — за недопоставку ещё и штрафуют.

Цена меняется каждый час: два пика в сутках, зимний максимум в году и шум,
который держится несколько суток. Пока игрока нет, время идёт по курсу
**игровые сутки за реальный час** — неделя отсутствия короче срока, который
даётся на исправление перед банкротством.

## Установка в Arch Linux

```bash
cd packaging && makepkg -si
```

Зависимости — только из официальных репозиториев: `python-textual`,
`python-rich`, `python-msgpack`, `python-platformdirs`. Ни одного пакета из AUR.

## Тесты

```bash
.venv/bin/python -m pytest              # всё
.venv/bin/python -m pytest -m "not slow"  # без бенчмарка догона
.venv/bin/ruff check . && .venv/bin/ruff format --check .
```

## Главное обещание

**Обновление игры никогда не теряет прогресс.** Каждое изменение структуры
сейва сопровождается миграцией и настоящим сейвом-фикстурой в
`tests/fixtures/saves/`; тест прогоняет все фикстуры через всю цепочку и
проверяет, что партия загружается и продолжает считаться. Фикстуры не
удаляются и не редактируются никогда.
